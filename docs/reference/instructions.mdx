Method names are shown in Rust snake_case; the Anchor TypeScript client exposes them in camelCase (`curve_buy` becomes `curveBuy`).

Common guard shorthand used below:

- **Bootstrap / Live**: `Market.status` must match, else `NotBootstrap` / `NotLive`.
- **Not frozen**: `Market.frozen` must be false, else `Frozen`.
- **Index required**: `Market.index_twap > 0`, else `NoIndex`.
- **Index fresh**: index required, and when `max_index_age_secs > 0` the last push must be no older than that, else `IndexStale`. See the [staleness guard](/concepts/price-index#staleness-guard).
- **Internal venue**: `Market.venue == Internal`, else `WrongVenue`. See [venues](/concepts/amm#venues).

### create_market

Lists a new underlying on the **internal venue**. Admin-gated in v1 (listing policy is enforced off chain; see [Listing a market](/guides/listing-a-market)). Initializes the market, its synth mint, the pool token account, the treasury token account, and (when `params.item_reserve > 0`) the item reserve token account, then premints the entire fixed supply and revokes the mint authority, all in one transaction: `curve_virtual_tokens` base units go to the pool account (the curve allocation), `max_open_interest` base units to the treasury (the hedging reserve), and `item_reserve` base units to the item reserve (backing [item swaps](/concepts/synth-token#item-swaps)), after which `SetAuthority(MintTokens, None)` makes the supply permanently fixed.

| Arg | Type | Description |
| --- | --- | --- |
| `collection` | `Pubkey` | Opaque underlying identifier; becomes the market PDA seed |
| `params` | `Option<MarketParams>` | Per-market override; `null` uses `Global.default_params` |

| Account | Constraints |
| --- | --- |
| `global` | `["global"]`, `has_one = admin` |
| `admin` | signer, mut (payer) |
| `market` | init, `["market", collection]` |
| `synth_mint` | init, `["mint", market]`, decimals 6; mint authority revoked before the transaction ends |
| `pool_token` | init, `["pool", market]`, token authority = market; receives the preminted curve allocation |
| `treasury` | init, `["treasury", market]`, token authority = market; receives the preminted hedging reserve |
| `item_reserve` | init, `["items", market]`, token authority = market; receives the preminted item-swap allocation (may be zero) |
| `sol_vault` | mut, `["vault", market]` |
| `token_program`, `system_program` | |

Guards: `curve_virtual_sol > 0`, `curve_virtual_tokens > 0`, and `units_per_item_micro > 0` whenever `item_reserve > 0`, else `ZeroAmount`. The market starts in `Bootstrap` with `venue = Internal` and `funding_index = FUNDING_ONE`. The admin also seeds the SOL vault with an untracked [rent-exemption buffer](/reference/pdas#the-sol-vault) so later outflows can never strand it below the rent-exempt minimum. Events: none.

### create_external_market

Attaches a market to a token that launched on an **external venue** ([Meteora](https://www.meteora.ag) DBC into a DAMM pool). This is the current launch path for new markets. The mint already exists and its supply is fixed, so there is no curve phase: the market is created directly `Live` with `venue = External`. Shorts are cash-settled against the insurance fund (see [Shorts](/concepts/shorts)), so no reserve tokens need to be drawn to open one. The item reserve token account is created empty; it is funded by a plain SPL transfer post-launch to back [item swaps](/concepts/synth-token#item-swaps). The mark price is oracle-pushed via [`push_mark`](#push_mark).

| --- | --- | --- |
| `collection` | `Pubkey` | Opaque underlying identifier; becomes the market PDA seed |
| `params` | `Option<MarketParams>` | Per-market override; `null` uses `Global.default_params` |
| `fee_receiver` | `Pubkey` | Recipient recorded as `Market.fee_receiver` |

| Account | Constraints |
| --- | --- |
| `global` | `["global"]`, `has_one = admin` |
| `admin` | signer, mut (payer) |
| `market` | init, `["market", collection]` |
| `synth_mint` | the externally launched mint (not a PDA; recorded as `market.synth_mint`) |
| `treasury` | init, `["treasury", market]`, token authority = market |
| `item_reserve` | init, `["items", market]`, `token::mint = synth_mint`, `token::authority = market`; created empty, funded by SPL transfer post-launch |
| `sol_vault` | mut, `["vault", market]` |
| `token_program`, `system_program` | |

Guards: admin only. No pool token account exists for external markets; [`curve_buy`](#curve_buy)/[`curve_sell`](#curve_sell) are unreachable (never `Bootstrap`) and [`amm_buy`](#amm_buy)/[`amm_sell`](#amm_sell) reject with `WrongVenue`. The SOL vault gets the same rent buffer as `create_market`. Events: none.

## Oracle

### push_index

Submits a floor/card price observation, in lamports per whole underlying unit. Only the configured oracle authority may sign. See [Price index](/concepts/price-index).

| Arg | Type | Description |
| --- | --- | --- |
| `price_lamports` | `u64` | Observed price per unit |

| Account | Constraints |
| --- | --- |
| `global` | `["global"]` |
| `oracle_authority` | signer, must equal `global.oracle_authority` else `Unauthorized` |
| `market` | mut |

Behavior:

1. Not frozen, else `Frozen`: while a market is frozen the index cannot move, so a compromised oracle cannot walk the TWAP breaker-step by breaker-step during the freeze. The safe resume sequence is admin unfreeze, then a fresh push; the [staleness guard](/concepts/price-index#staleness-guard) keeps index-priced operations blocked until that push lands.
2. `price_lamports > 0`, else `BadIndexValue`.
3. Rate limit: at least `min_push_interval_secs` since the last push (skipped for the first push), else `PushTooSoon`.
4. Breaker check: if the observation deviates from `index_twap` by more than `breaker_bps`, the market is frozen, `index_last_raw`/`index_last_ts` are recorded, the TWAP is **not** updated, and `BreakerTripped` is emitted. The instruction still succeeds.
5. Otherwise the TWAP absorbs the observation via the time-weighted EMA (`min(dt, window)/window` pull). The first push sets the TWAP directly. Emits `IndexPushed`.

### push_mark

External-venue markets only: submits the mark price, in lamports per whole underlying unit. The on-chain program never parses external pool bytes; the relayer computes the price from Meteora's public pool API and pushes it here. On chain the value is EMA-smoothed over `mark_window_secs` and rate-limited by `min_push_interval_secs`. There is no breaker on the mark: a bad push can only tilt the [funding](/concepts/funding) flow, which the daily clamp bounds, so its blast radius matches the trust already placed in the oracle key.

| Arg | Type | Description |
| --- | --- | --- |
| `price_lamports` | `u64` | Mark price per unit from the external pool |

| Account | Constraints |
| --- | --- |
| `global` | `["global"]` |
| `oracle_authority` | signer, must equal `global.oracle_authority` else `Unauthorized` |
| `market` | mut |

Guards: `venue == External` (`WrongVenue`), not frozen (`Frozen`), `price_lamports > 0` (`BadIndexValue`), rate limit (`PushTooSoon`). Events: none.

### curve_buy

Buys synth on the bonding curve with SOL. Transfers tokens from the preminted curve allocation in the pool account to the buyer's associated token account (created on demand). See [Launch curve](/concepts/launch-curve).

| Arg | Type | Description |
| --- | --- | --- |
| `sol_in` | `u64` | Gross lamports in (fee is deducted from this) |
| `min_tokens_out` | `u64` | Slippage floor, base units |

| Account | Constraints |
| --- | --- |
| `market` | mut, `["market", collection]` |
| `synth_mint` | mut, `["mint", market]` |
| `pool_token` | mut, `["pool", market]`; holds the curve allocation |
| `sol_vault` | mut, `["vault", market]` |
| `user` | signer, mut |
| `user_ata` | init_if_needed, ATA(user, synth_mint) |
| `token_program`, `associated_token_program`, `system_program` | |

Guards: Bootstrap, not frozen, `sol_in > 0` (`ZeroAmount`), `tokens_out >= min_tokens_out` (`Slippage`), `tokens_out > 0` (`ZeroAmount`). Fee: `sol_in * curve_fee_bps / 10000` accrues to `fee_lamports`. Emits `CurveTraded { is_buy: true, sol_amount: gross in }`.

### curve_sell

Sells synth back into the curve. Returns the tokens to the curve allocation in the pool account and pays SOL from the vault; the fee is taken from the SOL output.

| Arg | Type | Description |
| --- | --- | --- |
| `tokens_in` | `u64` | Base units to sell |
| `min_sol_out` | `u64` | Slippage floor, lamports |

Accounts: same as `curve_buy`.

Guards: Bootstrap, not frozen, `tokens_in > 0` (`ZeroAmount`), `tokens_in <= curve_tokens_sold` (`CurveSellTooLarge`), gross SOL out `<= curve_sol_raised` (`InsufficientVaultFunds`), net out `>= min_sol_out` (`Slippage`). Emits `CurveTraded { is_buy: false, sol_amount: net out }`.

### graduate

Permissionless transition from Bootstrap to Live once the raise target is met. Splits the raise into the [insurance fund](/concepts/insurance-fund) and the [AMM](/concepts/amm) reserves (under the launch convention `insurance_share_bps = 0`, so the full raise seeds the AMM), keeps a price-matched AMM seed from the unsold curve allocation in the pool account, **burns the unsold excess** (supply only shrinks after creation), and initializes the mark EMA and funding clock. See [Graduation](/concepts/graduation).

Args: none.

| Account | Constraints |
| --- | --- |
| `market` | mut, `["market", collection]` |
| `synth_mint` | mut, `["mint", market]` |
| `pool_token` | mut, `["pool", market]` |
| `token_program` | |

Guards: Bootstrap (`NotBootstrap`), not frozen, `curve_sol_raised >= graduation_target_sol` (`TargetNotReached`), index required (`NoIndex`), computed AMM tokens `> 0` (`ZeroAmount`). Emits `Graduated`.

### close_position

Settles the short's PnL in SOL and closes the position account, refunding its rent to the owner. PnL is `entry_notional - (size valued at the current index)`: a profit (the index fell) is paid to the owner from the insurance fund, bounded by the fund balance; a loss (the index rose) is deducted from collateral into insurance. The owner receives their collateral plus or minus PnL.

Args: none.

| `owner` | signer, mut |
| `system_program` | |

Guards: not frozen (`Frozen`), index fresh (`NoIndex` / `IndexStale`). Emits `ShortChanged`.

## Item swaps

Value-based exchange between the synth and registered on-chain copies of the underlying (vaulted-card NFTs, collection NFTs). Both directions price one item at `index_twap * BASE_UNITS_PER_NFT * units_per_item_micro / mark_ema / 1e6` base units: tokens equal in value to one item at current prices, with `units_per_item_micro` restoring the item's real size against the launch-scaled index, and the smoothed mark rather than spot so a sandwich cannot move the rate inside one block. See [Item swaps](/concepts/synth-token#item-swaps).

### register_item

Registers an item mint as depositable into a market's item pool. Admin-gated in v1 (the relayer verifies off chain that the mint is a genuine vaulted copy of the market's underlying); on-chain collection verification is the planned replacement.

Args: none.

| Account | Constraints |
| --- | --- |
| `global` | `["global"]`, `has_one = admin` |
| `admin` | signer, mut (payer) |
| `market` | |
| `item_mint` | the SPL mint of the copy (0 decimals, supply 1) |
| `registration` | init, `["item", market, item_mint]` |
| `system_program` | |

Guards: admin only. Events: none.

### deposit_item

Deposits one registered item into the market's escrow and receives tokens worth the item from the item reserve, **net of a 0.7% fee** (`curve_fee_bps`): `tokens_out = index_twap * BASE_UNITS_PER_NFT * units_per_item_micro / mark_ema / 1e6`, less the fee, which stays in the item reserve.

Args: none.

| Account | Constraints |
| --- | --- |
| `market` | mut, `["market", collection]` |
| `item_mint` | the registered item's mint |
| `registration` | `["item", market, item_mint]`; a missing or mismatched account fails the seeds constraint (`ItemNotRegistered`) |
| `item_reserve` | mut, `["items", market]` |
| `escrow_item` | init_if_needed, ATA(market, item_mint); the market's escrow for this item |
| `user` | signer, mut |
| `user_item` | init_if_needed, ATA(user, item_mint) |
| `synth_mint` | mut, `address = market.synth_mint` |
| `user_token` | init_if_needed, ATA(user, synth_mint) |
| `token_program`, `associated_token_program`, `system_program` | |

Guards: not frozen, index fresh (`NoIndex` / `IndexStale`), `mark_ema > 0` (`NoMark`), `item_reserve.amount >= tokens_out` (`ItemReserveDepleted`). Works in **both phases**: during Bootstrap the mark EMA is seeded at the curve's opening spot and stepped by every curve trade. Increments `items_deposited`. Emits `ItemSwapped { deposited: true }`.

### withdraw_item

The mirror image: the user pays tokens worth one item (same formula, evaluated at withdrawal time) **plus a 0.7% fee** (`curve_fee_bps`) into the item reserve and takes a copy out of the market's escrow; the extra fee accrues to the item reserve.

Args: none. Accounts: same as `deposit_item`.

Guards: not frozen (both phases), index fresh (`NoIndex` / `IndexStale`), `mark_ema > 0` (`NoMark`), `escrow_item.amount >= 1` (`ItemNotInEscrow`); the user must hold `tokens_in` in their ATA (SPL transfer fails otherwise). Decrements `items_deposited`. Emits `ItemSwapped { deposited: false }`.

## Keeper

### accrue_funding

Permissionless funding crank. On the internal venue it refreshes the mark EMA from the AMM spot; on the external venue it uses the [oracle-pushed mark](#push_mark) instead, requiring `mark_ema > 0` (`NoMark`) and, with `max_index_age_secs > 0`, a mark no older than that (`IndexStale`). It then computes the clamped funding rate from the mark/index premium and advances the global funding index. The effective elapsed time is capped at one day per crank: a late crank forfeits the excess rather than applying the current premium retroactively to an unbounded gap. See [Funding](/concepts/funding) for the math.

Args: none.

| Account | Constraints |
| --- | --- |
| `market` | mut, `["market", collection]` |

Guards: Live, not frozen, index fresh (`NoIndex` / `IndexStale`), external venue mark present and fresh (`NoMark` / `IndexStale`), at least `min_crank_interval_secs` since the last crank (`CrankTooSoon`), resulting funding index must stay positive (`MathOverflow`). Emits `FundingAccrued`.

### liquidate

Permissionless, cash-only liquidation of an undercollateralized short. No tokens move. The short's realized loss (capped at its collateral) goes to the insurance fund; the liquidator takes a SOL bonus (`liq_bonus_bps` of notional, capped at the remaining equity); the owner keeps any remainder. See [Liquidations](/concepts/liquidations).

Args: none.

| Account | Constraints |
| --- | --- |
| `market` | mut, `["market", collection]` |
| `sol_vault` | mut, `["vault", market]` |
| `position` | mut, `["short", market, position_owner]` |
| `position_owner` | mut, CHECK: must equal `position.owner` else `Unauthorized`; receives any remainder |
| `liquidator` | signer, mut; receives the bonus |
| `system_program` | |

Guards: Live, not frozen, index fresh (`NoIndex` / `IndexStale`), liquidatable when `collateral * 10000 < (size valued at index) * maintenance_cr_bps`, else `NotLiquidatable`. Emits `Liquidated` (`payout` is the liquidator bonus).
