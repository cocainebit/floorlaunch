## Current status

The core Anchor program is live on Solana mainnet
(`QsixfrupxfVEDDYuQsR4vJcE58bbNfctD9WjijM9BjM`). The current architecture
launches every token as a [Meteora](https://www.meteora.ag) Dynamic Bonding
Curve pool that migrates to DAMM v2, replacing the retired internal commas
bonding curve and AMM. On that venue the token is a fixed-supply (1B) external
SPL mint with revoked authority, branded as the collectible via Metaplex
metadata, tradeable through Jupiter and visible on Axiom, Photon, and Solscan.

The v1 price feed (the [relayer](/oracle/architecture)) is built (TypeScript,
`relayer/` in the repo): live [Magic Eden](https://magiceden.io) listing-ladder
estimation for NFT floors, operator-attested graded-card indexes seeded from
[Collector Crypt](https://collectorcrypt.com) floors with live [Pyth](https://pyth.network)
SOL/USD conversion, a Meteora pool mark source (`push_mark`), disagreement
gates, and YAML per-market config. NFT floors read live; a fully automated
graded-card feed is still pending, so graded prices are operator-attested for
now: copy should not overstate that automation.

An adversarial review pass on the funding, liquidation, and vault-conservation
math ran on 2026-07-24; its findings (funding-crank dt cap, oracle pushes
refused while frozen, vault rent buffer) are fixed and reflected in the concept
pages.

## Meteora DBC migration

The move off the internal curve onto Meteora is the defining v2 change.

- **Launch and trading (built, in final validation):** DBC pool launch with
  collectible metadata, the `/token-metadata` endpoint,
  [`create_external_market`](/reference/instructions#create_external_market)
  attach, relayer `push_index` + `push_mark`, `/markets` reading live Meteora
  pool state, and Jupiter spot routing. This path is gated behind a launch flag
  until a live mainnet pass.
- **Cash-settled shorts and item-swap fee (program change in progress):** the
  short side is reworked from the retired CDP draw-and-repay model to
  [cash-settled](/concepts/shorts) positions that settle PnL in SOL against the
  [insurance fund](/concepts/insurance-fund), and the
  [item swap](/concepts/synth-token#item-swaps) gains its 0.7% fee. This is the
  hedging and redemption model documented throughout these pages.

Remaining on this path: a ***commas***-branded DBC config key so launches run
through Meteora end to end from the commas UI, and a devnet/mainnet dry run of
the full DBC path before broad launches.

## The commas token

A ***commas*** token will launch on [pump.fun](https://pump.fun). The
announcement and the official contract address will come from
[@commasdotart on X](https://x.com/commasdotart) and nowhere else; treat any
other address as fake. The protocol does not depend on it: every market's
token works the same with or without it.

## Planned work

Roughly in build order. Items are planned, not promised.

### Production graded-card sources

The NFT side reads live from Magic Eden; graded cards are operator-attested
today. Graded production means wiring the full
[oracle pipeline](/oracle/card-pipeline): subscription aggregator APIs plus
[eBay](https://www.ebay.com) sold prints plus tokenized-venue cross-checks
([Collector Crypt](https://collectorcrypt.com), [Courtyard](https://courtyard.io)),
MAD outlier rejection, sanity bands from capitalized bids, cross-source
agreement gates, and paging alerts. The NFT side additionally gains a
[Tensor](https://www.tensor.trade) bid leg (see [NFT pipeline](/oracle/nft-pipeline))
once API keys are provisioned.

### Long-side staked funding

v1 settles funding against the short side and the insurance fund only. v2 adds
an opt-in staking pool so token holders who stake participate in funding flows
directly, tightening the peg from the long side.

### On-chain item verification

Item-swap registration is admin-gated in v1 while vault provenance is verified
off chain. Planned: on-chain collection verification to replace admin-gated
`register_item`.

### Permissionless listing

Replace admin gating with on-chain depth attestations, so anyone can list a
market whose underlying provably meets the [listing criteria](/guides/listing-a-market).

### Timed auction frames

An alternative launch mode: time-gated targets where a launch fails cleanly if
demand does not materialize on schedule, instead of lingering half-launched.

### Audits

Independent review of the funding math, liquidation edges, and vault
accounting. A fuzz harness for the short and funding paths is part of this
work.
